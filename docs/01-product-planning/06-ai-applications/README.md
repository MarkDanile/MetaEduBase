## APP-005: 企业 360 背调工作台

业务目标：面向招商、投资和管理层，在企业入驻、招商准入或投决会前，通过企查查 MCP、背调 Skill 和内部客户信息 MCP 汇总内外部事实，生成可归档、可追溯、可人工确认的企业背调报告。

核心能力：

- 输入企业名称或统一社会信用代码，并按企查查实体锚定规则确认主体。
- 调用企查查 MCP 获取工商登记、股权、实控人、受益所有人、风险扫描、司法和经营相关公开事实。
- 调用内部系统 MCP 获取园区内租赁、缴费、合同、工单、历史合作和客户状态信息。
- 通过背调 Skill / SOP 组织分析流程，生成固定结构报告。
- 区分事实数据、AI 分析、待人工确认项和最终人工复核结论。
- 记录工具调用、数据来源、时效层级和报告版本，支持归档进入投决材料。

底座依赖：

- P2：稳定 RAG grounding、报告引用、结构化抽取、真实样例验收。
- P3：MCP 注册与调用治理、Skill 注册与执行、AI Chat 会话化、任务产物、权限与审计。
- 关联需求：REQ-041 / REQ-042 / REQ-043 / REQ-044 / REQ-045 / REQ-046。

首个建议切片：先做“企业主体确认 -> 企查查 MCP 外部事实获取 -> 内部 MCP mock 数据 -> 背调 Skill 生成报告草案 -> 人工确认区 -> 报告归档”的 V0 闭环。真实内部系统接入可先用契约和 mock 固化边界。

## 应用广场与独立应用关系

AI 应用广场是应用的注册、发现、治理和发布入口，不是应用本体。后续每个 AI 应用都应同时满足两点：

- 可以作为独立业务模块自主访问，拥有自己的路由、页面交互、配置、业务数据和验收标准。
- 可以注册进 AI 应用广场，由广场负责展示、分类、搜索、启用 / 禁用、发布状态和入口跳转。

建议父需求：`REQ-011: AI 应用广场与应用注册中心`。

```text
AI 应用广场
  - 展示 / 搜索 / 分类
  - 注册 / 编辑 / 启用 / 禁用 / 归档
  - 发布状态 / 可见性 / 入口类型
  - 跳转到内部路由、外部链接、嵌入页或 API

独立 AI 应用
  - 独立路由
  - 独立页面交互
  - 独立业务数据
  - 独立配置
  - 独立验收标准
```

首期不要做开放插件市场、评分收藏、第三方上传或完整 workflow 编排；先把“可注册、可展示、可独立访问、可禁用、可后续发布”的产品骨架打稳。

## APP-001: 课程能力图谱智能体工具

业务目标：自动构建、动态管理与智能应用课程能力图谱，实现《新型建材物理性能检测》课程能力结构的系统化梳理与可视化呈现，支撑个性化学习路径规划和资源推荐。

核心能力：

- 解析 Word、PDF、TXT 等课程教学文件，单篇文本处理字数目标不少于 3 万字。
- 自动识别课程能力点、能力层级关系、知识技能支撑要求。
- 构建能力图谱，识别能力点属性：知识应用、技能操作、综合素养。
- 识别关系类型：能力递进、能力关联、能力支撑。
- 映射专业能力、方法能力、社会能力三维目标，并建立能力点与知识技能、职业素养的关联矩阵。
- 可视化呈现能力图谱，支持多轮对话调优图谱内容。

底座依赖：

- P1：文档解析、结构化抽取、知识图谱抽取、RAG 问答和来源展示。
- P2：图谱关系召回、抽取 schema 稳定化、模板匹配可解释化、RRF 融合。
- P3：当图谱规模和复杂关系推理成为瓶颈时，再评估 Neo4j 或多引擎图谱能力。

首个建议切片：以一门课程和一组真实课程文件为样例，先完成“文件解析 -> 能力点抽取 -> 能力关系初稿 -> 人机对话修订 -> 图谱展示”的最小闭环。

## APP-002: 智能预习规划与导学智能体

业务目标：基于课程能力图谱与学生学情，智能规划预习任务、推送预习资源、诊断预习效果，实现课前预习的个性化设计与精准支持。

核心能力：

- 解析课程能力图谱，识别学习内容所需前置能力与知识基础。
- 通过微型测试诊断学生前置学情。
- 基于能力缺口生成个性化预习方案，明确预习目标和预习内容。
- 推送微课视频、知识卡片、前置测试、拓展阅读等资源。
- 自动诊断预习效果，识别薄弱环节并推送补救资源。
- 支持多轮对话问答，并将高频难点标记为课堂重点讲解候选。

底座依赖：

- P1：RAG 问答、资源管理、基础知识图谱和文档抽取。
- P2：能力图谱关系召回、学生学情数据结构、资源推荐规则和测试题管理。
- P3：多模态资源理解、复杂学习路径优化和大规模学生画像。

首个建议切片：基于 APP-001 的能力图谱，选择一个课前主题，生成预习任务和微型测试的人工可审查草案。

## APP-003: 个性化学习资源推荐智能体

业务目标：基于学生画像与学习情境实现精准资源匹配与智能推送，提升学习资源利用效率与学习体验。

核心能力：

- 构建学生动态画像，整合静态属性标签和动态行为标签。
- 管理并推荐微课视频、知识卡片、测试题库等不少于 3 种资源类型。

底座依赖：

- P1：资源管理、基础 RAG、知识节点和来源解释。

业务目标：基于遗忘曲线与学习记录，智能规划复习任务、推送巩固内容，实现课后复习的个性化安排与高效巩固。

核心能力：

- 支持学生自主记录已学内容与学习时间。
- 基于艾宾浩斯遗忘曲线和通用记忆规律，计算知识点最佳复习时机。
- 生成个性化复习计划，明确复习优先级和建议时长。
- 推送知识点速查、技能点回顾、思维导图等复习资源。
- 通过内置微型测试验证记忆保持度。
- 支持学生反馈复习状态，并动态调整后续复习计划。

底座依赖：

- P1：知识点、资源和基础问答能力。
- P2：学习记录、微测验、能力图谱和资源推荐。
- P3：规模化个性化调度、长期学习画像和效果观测。

首个建议切片：先做知识点级复习计划生成和自评反馈，不直接做复杂长期推荐模型。
