## 使用规则

- 本目录记录阶段目标、三条轨道、完成标准、开放事项和事实源。
- 不写实现步骤；实现步骤进入 `docs/02-delivery-plans/02-plans/*`。
- 不把每个想法都拆成阶段文件；新增里程碑前先更新 `01-roadmap.md` 并确认它确实是阶段级目标。
- 阶段内的具体需求、bug、技术债和运营任务仍进入 backlog、requirement、technical-debt、spec 或 plan。
