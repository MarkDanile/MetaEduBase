# Milestones — 里程碑详情

本目录只在里程碑需要展开时使用。默认先维护 `docs/01-product-planning/01-roadmap.md` 的总览表，不为每个想法创建单独文件。

## 何时新建

- 里程碑横跨多个迭代或多个需求族。
- 需要记录阶段目标、边界、非目标和验收指标。
- 需要给 AI IDE 提供稳定上下文，避免每次从聊天记录恢复背景。

## 模板

```md
# Mx: 里程碑名称

Status:
Owner:
External:

## Goal

## Non-Goals

## Iterations

## Key Backlog Items

## Evidence
```

里程碑文件不写实现步骤；实现步骤进入 `docs/02-delivery-plans/02-plans/*`。
